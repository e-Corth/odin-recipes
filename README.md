# odin-recipes
This is a basic HTML project from The Odin Project. It’s a simple recipe website that includes a main index page linking to three individual recipe pages.
Each recipe page contains a short description, a list of ingredients, and step-by-step cooking instructions, along with an image of the dish.
The goal of this project was to practice the fundamentals of HTML structure, including headings, lists, links, images, and basic file organization.
